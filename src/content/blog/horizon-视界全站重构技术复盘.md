网站的名字叫 **Acretiondisk**（吸积盘）。过去很长一段时间里，这个名字只是页眉角标里一个安静的词汇；博客的前端则是一套标准的卡片栅格、圆角阴影与多主题切换开关。直到今天，我决定推翻一切惯性模板，把整个站点的前端表现层从零重写成一台真正运转的「**黑洞观测仪器——HORIZON（视界）**」。

![HORIZON（视界）概念主图：事件视界、等离子橙光环与仪器准星](/images/horizon-rewrite/cover.webp)

动手之前，我先在工程交接文档 [CLD.md](https://github.com/AnAcretiondisk9986/AnAcretiondisk9986.github.io/blob/main/CLD.md) 顶部划定了两条不可逾越的边界：

> 1. **只重写表现层**：`layouts / components / pages / styles / scripts` 推倒重来，站点内容 Markdown、`src/content.config.ts`、`src/data/*.json`、构建期图片本地化脚本、管理后台 `admin/` 以及 AI 算力额度代理的数据契约一概不动；

## 一、视界本体：Fragment Shader 里的史瓦西黑洞

首页首屏不是一张预先渲染好的视频或 GIF，而是一段直接跑在像素着色器里的实时引力光线追踪器（`src/scripts/hz/disk.ts`）。从相机向屏幕每个像素发射一条光线 `rd`，在史瓦西黑洞引力势场中按广义相对论有效势方程不断偏折轨迹：

```glsl
// 沿广义相对论有效势累加引力偏折加速度
float dt = clamp(0.042 * (r - 0.78), 0.022, 0.42);
if (abs(pos.y) < 0.35 && r < diskOut + 0.4) {
  dt = min(dt, 0.12); // 赤道吸积盘附近收紧步长，避免穿层锯齿
}
float r5 = pow(max(r, 0.48), 5.0);
vec3 acc = -1.5 * h2 * pos / r5;
vel = normalize(vel + acc * dt);
pos += vel * dt;
```

为了兼顾精密感与笔记本核显帧率，最初的 78 步积分在后续精修中升级到 **`#define STEPS 112`**，同时加入自适应步长限制与动态 HiDPI 降档开关：连续 18 帧耗时超过 `42ms` 时，自动将 `dprCap` 从 `1.65` 平滑下调至 `0.95`，避免页面掉帧；离开视口或标签页隐藏则由 `IntersectionObserver` 与 `visibilitychange` 立刻挂起 `requestAnimationFrame`。

![相对论多普勒聚束与引力弯曲轨道示意图](/images/horizon-rewrite/doppler-orbit.webp)

光线穿越赤道平面 `y = 0` 且落在吸积盘内外半径之间时，着色器并不只是简单画一个橘色圆环，而是同时求解三层物理视觉特征：

1. **开普勒差动旋转与多层 FBM 等离子丝**：角速度随半径按 `4.4 / pow(hr, 1.32)` 衰减，越靠近内稳定圆轨道的气体缠绕越紧；再叠加 5 层分形布朗运动湍流，拉伸出高频细丝与亮暗环道。
2. **相对论多普勒聚束（Doppler Beaming）**：用轨道切向速度与视线夹角 `cosTheta` 计算 `doppler = pow(clamp(1.0 + vOrb * cosTheta, 0.28, 2.25), 3.0)`。迎向观测者的一侧（左侧）发生显著蓝移增亮，内缘迸发出淡淡的电弧冷光；背离的一侧（右侧）红移暗沉成深绯余烬。
3. **双层光子环与纯净天球**：在黑洞阴影临界半径 `minR ≈ 1.50 * Rs` 附近叠加指数衰减的光子环与高频微弱闪烁日冕；在最新迭代里，我移除了原本用于背景折射的二次元前景图，只保留纯黑虚无深空带出微弱星野与引力增亮，并将色彩送入 ACES Filmic 色调映射与 1.28 倍饱和度补偿。

![首页 VOID 模式：实时 WebGL 史瓦西黑洞与液态玻璃顶栏](/images/horizon-rewrite/home-void.webp)

点击右上角 `VOID / PLATE` 切换为亮色「照相底片」模式时，整个着色器通过线性插值平滑反相：虚无化作冷冽的观测底片灰白（`#eae8e2`），炽烈的吸积盘则转译为高饱和冷蔚蓝与紫罗兰干涉纹，中心奇点仍旧留出一轮纯净纸白。

![首页 PLATE 模式：照相底片白洞反相光谱](/images/horizon-rewrite/home-plate.webp)

## 二、全站外壳与排版体系：从反色 HUD 到自托管多语字库

最早第一版的顶栏使用纯 CSS `mix-blend-mode: difference`，在纯色画布上极有仪式感，但实际滚动经过黑洞光子环、高饱和课程方块与复杂摄影图版时，混合反色会让导航文字变得浑浊、甚至与背景纹理打架。因此后来将 `.hz-hud` 升级为双主题半透明**液态玻璃顶栏**——暗色模式与亮色模式各自配备 `backdrop-filter: blur(22px) saturate(190%)`、顶部高光内描边及低不透明度折射高光渐变，同时保留四周 1px 裁切标与左右垂直遥测读数（实时光标坐标、页面下潜深度 `DEPTH`、UTC 时钟与修正儒略日 `MJD`）。页脚的「回到视界之外」则由原先占幅过宽的长按钮收敛为一枚干净利落的 `50×50px` 圆形 `↑` 指针。

在字体与多语种规范上，今天经历了一次「发散 → 收敛 → 精准强化」的过山车：

- **去冗余与防溢出**：先清除了会引发长英文单词撑爆卡片容器的宽体展示字与轮廓异常的字库分片，全面回归自托管 `Noto Sans SC` / `Noto Serif SC` 搭配 `Anthropic Sans / Serif / Mono` + `JetBrains Mono`（`Unbounded` 严格限制在品牌字标与页脚巨型英文底标）。
- **全域日文角标体系**：最后将全站所有显式标注 `lang="ja"` 的仪器代号与微标（如首屏 `事象の地平線`、`事象境界へ降下`，光谱栏 `発光スペクトル`、`光波長解析`，学业轨 `履修軌道`、`転科軌道修正`，以及菜单、页脚、门禁、404 与额度页的日文状态标）统一切换为 **`Dela Gothic One`**，把字号提升至 `0.82rem–0.86rem`、字重锁定正体不加粗，保证粗黑几何日文徽标在小标签下依旧笔锋犀利不糊字。
- **零 ClientRouter**：放弃 Astro 默认的 JS 客户端接管路由，改用原生 `@view-transition { navigation: auto }` 实现跨文档转场——全站交互脚本退回最朴素的「按页加载、即用即毁」，不再需要绕弯处理 `astro:page-load` 状态泄漏。

## 三、时间即光谱，图像即重力场

### 文章目录：发射光谱图与大小双态封面

每篇文章在构建期都会被 `src/lib/horizon.ts` 计算出两个风格化天文学参数：**质量**（剥离 Markdown 标记、代码块与链接后的有效字符数）与**红移 $z$**（`days / 365`，仅用于把旧文章的标题与左侧刻度条慢慢往暖红、暗沉方向推进，让整条时间线呈现一条真实的光谱帯）。

`/blog/` 顶部的发射光谱带与下方列表双向联动——悬停任何一根谱线就能锁定并高亮对应的历史观测记录，并实时显示 `MJD` 与 `z`。至于封面展示逻辑，在两轮打磨中确定下来最终形态：
- **桌面精细指针**：悬浮文章行时浮起一枚 **`204×132px`** 的圆角小预览窗，通过替换 `<img>` 节点绕过 CDN 降级脚本的 `WeakSet` 状态锁；
- **移动端与触控端**：无法触发 hover，于是直接通过 `@media (max-width: 720px)` 与 `(hover: none) and (pointer: coarse)` 在文章行左侧固定呈现圆角缩略图。

![文章目录页：时间红移发射光谱与桌面悬浮预览透镜](/images/horizon-rewrite/blog-spectrum.webp)

### 图像档案：无限全集、无界缩放与去编号哲学

第一版图像透镜场（`/gallery/`）沿用了每扇区 32 张的分页切割，且容器硬锁 `4:3` `object-fit: cover`。这在看大量竖幅插画和摄影作品时非常割裂。重构之后：

1. **移除分扇区与 4:3 裁剪**：透镜场直接挂载当前池全量图版（独立收藏 99 幅 / 随文影像 / 全部），利用 `hydrateNode` 结合视口邻近阈值动态水合图片 `src` 并剔除远端 DOM；同时放开画框宽度与高度限制，按每张图片原本的自然长宽比例完整显影。
2. **以光标与双指为锚的缩放场**：新增 `fieldZoom`（`20%–240%`）连续缩放。无论是桌面端的**鼠标滚轮 / 触控板捏合**，还是触屏端通过指针集合追踪的双指捏合，都会围绕光标或双指中心点等比缩放坐标与图版尺寸（公式 `targetX += mx * (1 / prevZoom - 1 / nextZoom)`），并同步缩放背景坐标网格步距。滚轮向后一拉，几十张作品立刻在网格视野里收束成片。
3. **归还纯净视觉**：响应后期精修要求，彻底去掉了透镜场、索引网格、灯箱与首页「引力透镜图版」里的作品标题、左下角锁存框与 `PL.XXX` 序列编号；同时首页的 4 幅图版条内嵌完整 99 图静态池，前端每次加载以 Fisher–Yates 洗牌随机抽样 4 张展示。

![图像档案透镜场：Zoom Out 缩览模式与原比例图版群落](/images/horizon-rewrite/gallery-field.webp)

## 四、「学业」二级页：跨五年百门课程的 Bento 拼贴求解器

为了让本科五年的全部课程（原信管专业 24 门课程，转专业后五年制临床医学专业 75 门课程 + 大四「医院见习」 + 大五「医院实习」，共计 101 个图块）排出一面零空隙、零重叠的视觉墙，我们在构建期用 TypeScript 写了一个离散网格装箱求解器（`src/lib/academics.ts`）：

- **严格无缝拼版与错落大块**：桌面按 24 列、平板按 12 列、手机按 6 列动态装箱。高学分核心主课按 `totalCols >= 24 ? 2 : 1` 自动升格为两行高的 Hero 大块；大四「医院见习」占满 2 行全宽，大五「医院实习」占满 4 行全宽。`packTrackWall()` 再将原专业 2 学期与临床专业 10 个阶段纵向紧密焊死成两条连续拼贴墙，中间仅用一条压印「转专业 · 転科軌道修正」的细线隔开；左侧第一列新增与网格严格共享 `grid-row` 轨道的 **12 段纵向年份坐标轴**，确保每个学期刻度圆点精确落在对应首行基线上。
- **三态底纹与原地 3D 翻转**：原「互认」学分直接归入已修（实色 38 门 / 在修 45° 斜纹 12 门 / 待修点阵虚框 51 门），不再单设标签混淆视线。取消侧边抽屉后，点击任意卡片都在原地沿 `perspective: 1100px` 执行 `rotateY(180deg)` 翻转，背面极简地只保留**开课部门**与**成绩**（未录入显示 `NULL`）。（踩坑备忘：绝对不能给 `.hz-tile__inner` 的外层 `.hz-tile` 加 `overflow: hidden`，否则 Chromium 会将 `preserve-3d` 压平，必须把裁剪限制在内层 `.hz-tile__face` 上并配合 `backface-visibility: hidden`。）

![学业板块拼贴墙：原信管斜体、转专业轨道线与临床阶段 Serif Black + Google Sans Italic 英文译名](/images/horizon-rewrite/academics-wall.webp)

最后也是视觉反差最强烈的一步排版精修：

1. **后缀括号规则化**：`formatCourseTitle()` 在构建期扫描全部课程名称——凡数字编号（包含括号序号与 `体育3` / `体能测试4` 等尾随数字）统一转写为真 Unicode 罗马数字 `Ⅰ–Ⅳ`（`\u2160`–`\u2163`，绝不用拉丁字母 `I` 混代）；凡 `（实践）`、`（理论）`、`（D）`、`（体能素质）`、`（毕业考）` 等括号标注，一律剥离括号降格为浅色、小字号、常规字重的 `.hz-tile__sub` 附属标签。
2. **双轨中西文字体裁切自托管**：转专业前使用 **粗斜体**；转专业后 77 个阶段/课程全部补充医学英文译名，英文小字采用 **`Google Sans Italic`** 变体字体，中文大字则利用 Python `fontTools.varLib.instancer` 从可变字库实裁出 **`wght=900` 真实 `Noto Serif SC Black`** 静态子集（仅约 171 KB，无需向第三方 CDN 发请求），同时将临床网格行高从 `92px` 扩展至 `134px`（移动端 `118px`），配合 `computeTitleRem()` 字号求解器，最终在桌面端和手机端都实现零裁切溢出。

## 五、回到阅读本质：超宽屏居中、折叠侧栏与无封面阅读

全站改版推送上线后，我在超宽带鱼屏上打开一篇正文检查，立刻发现了一个尴尬的 CSS Bug：原本写给双栏布局的 `justify-content: space-between` 配合固定的 `268px` 左边栏与 `var(--measure)` 正文列，在宽屏容器下把整个正文硬生生推到了窗口最右侧，屏幕正中反而留出一大块黑洞般的空白。

最终在最后一轮提交 `c1fa80a` 中把正文体验一并收口：

1. **对称三栏绝对居中**：在 `>= 1220px` 视口下将 `.hz-entry__grid` 改写为 `minmax(196px, 1fr) minmax(0, var(--measure)) minmax(196px, 1fr)`，并用 `.hz-entry__head-main` 将文章主标题与摘要框定在同样的 `var(--measure)` 居中轴线上。这样无论屏幕是 16:9、`2560×1080` 21:9 超宽屏，还是侧栏收起态，标题与正文的视觉中心线始终稳稳落在视口正中（偏心距 `0px`）。
2. **通用可收起 / 展开侧栏**：在边栏顶部标题行、文章页头信息条以及桌面收起态的左上角分别安置控制按钮（同步支持 `[` 快捷键），状态持久化进 `localStorage`，并用一段贴在 DOM 上的微内联脚本在首帧渲染前同步 `data-rail-collapsed`，杜绝页面刷新时的布局闪烁；窄屏端收起时则退化为文末手风琴开关。
3. **移除文内封面**：文章正文头部不再重复展示巨大的封面图，把视觉空间完整让给标题、导语与首段首字下沉；封面只留在文章列表的桌面悬浮预览与移动端左侧卡片中履行检索使命。

![文章阅读页超宽屏效果：对称三栏居中正文、可收起边栏与无封面纯净版面](/images/horizon-rewrite/entry-centered.webp)
